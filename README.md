# Тёмные земли

Экшен-RPG для Android в духе Zenonia 5 с идеями из Albion Online: вид сверху, мрачная рисованная графика, 6 классов × 3 подкласса (выбор на 10-м уровне), активные и пассивные навыки, мастерство навыков от применения, сбор ресурсов и крафт по тирам, износ снаряжения, зоны опасности.

**Скачать APK:** раздел Releases → `apk` → `dark-realm.apk`. После установки игра обновляется сама.

## Как устроено
- `src/` — код игры (Phaser 3), `web/` — страница и стили, сборка — `npm run build:web` в `www/`.
- `src/data/` — классы и навыки, предметы, монстры, локации, задания: баланс правится здесь.
- `src/art/` — процедурная графика. Любую текстуру можно заменить своей картинкой: положите PNG в `assets/` и пропишите в `assets/manifest.json`, например `{"prop_house_0": "props/house.png"}`.
- Каждый пуш в `main` собирает APK через GitHub Actions и публикует обновление.
